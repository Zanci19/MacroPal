The Fix

One line of CSS fixes the centering issue:

CSS Change: 
.demo-app-container--portrait > * {
  width: calc(100vh * 9 / 16);
  max-width: 100vw;
  height: 100vh;
  max-height: calc(100vw * 16 / 9);
  box-shadow: 0 0 40px rgba(0, 0, 0, 0.5);
  flex-shrink: 0;  ← NEW: Prevents shrinking, ensures centering
}

Why This Works

  1. Prevents Shrinking: flex-shrink: 0 tells the flex child not to shrink below its defined width
  2. Maintains Explicit Width: The width: calc(100vh * 9 / 16) is respected exactly
  3. Enables Flexbox Centering: With a fixed width, the parent's justify-content: center can properly center the element
